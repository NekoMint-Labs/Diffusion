# Checkpoint 00 / product understanding

The Field carries unfinished thought. Messages record the reasoning that happened; they are not the product's main state. Sources are subordinate external references with honest inspection limits. Selection is temporary attention, not a group or a model request. It wakes only existing relations, never moves geometry, and does not invent edges.

Only a user may make lasting commitments: own a Ghost, confirm a relation, or form a Crystal. Model outputs are bounded semantic candidates routed through independent Core permissions. Camera, dragging and the local Probe cue remain immediate without networking. A Region is emergent spatial activity, never a folder or frame. Relations are sleeping phenomena, not permanent arrows. Conversation is a temporary manuscript surface that returns to the Field. Web and Desktop share one React UI, with native capabilities behind an adapter. Warm Light and Dark are first-class. Reference products contribute primitives only, never their ontology.
