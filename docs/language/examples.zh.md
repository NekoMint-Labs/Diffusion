# Diffusion Chinese Language Examples

These cases are deliberately uneven. Good Diffusion language should not look like one copywriter polished every sentence to the same finish.

Format:

- **USER LANGUAGE** — what the person actually said;
- **BAD AI VERSION** — common drift to avoid;
- **DIFFUSION THOUGHT** — one possible AI Thought Proposal;
- **DIFFUSION QUESTION** — one concrete follow-up;
- **DIFFUSION RELATION** — a short relation token when the case provides two ideas to connect.

---

## 01 · 要不要读研

**USER LANGUAGE**  
我不确定要不要读研。

**BAD AI VERSION**  
你正在面临一个关于长期职业发展与个人成长价值的重要选择。

**DIFFUSION THOUGHT**  
现在还没有哪一边明显到值得马上定下来。

**DIFFUSION QUESTION**  
你现在最缺的是哪一条信息？

## Review notes

The good versions intentionally vary:

- some are almost verbatim;
- some compress a relation;
- some add one new practical possibility;
- some leave roughness in place;
- none need to sound equally clever.

A future prompt change should be suspicious if it makes all 32 cases sound like the same author.
