## Diffuse 单步

### 基线

[原始记录](baseline-diffuse.json)

缺一个问题：“需要”的可观察定义是什么？没有它，访谈容易把“想要”当成“需要”。

本条原文、画布、阅读器、Keep 后和 JSON 恢复后文本逐字一致。

### 候选

[原始记录](candidate-diffuse.json)

在还没有访谈或试用结果之前，先定义一个不依赖私人作业/成绩的“需要”信号：学生是否会主动来问这个复习工具，或试用后是否愿意再用？
