# Historical tools

These files preserve earlier verification implementations. They are not maintained commands for
the current application and are not part of its verification gates.

`capture-visual.mjs` is the original Phase 2.5 capture script, moved here without changing its bytes.
Its shortcut-remapping flow, Settings selectors, dependency import and relative root assumption
belong to that earlier checkout. Do not run it from this directory or install additional packages
to make it appear current. Reproduce that historical pass from its original revision if needed.

For current captures and source snapshots, use [the maintained script instructions](../../../scripts/README.md).
Mounted-application verification is described in [Testing](../../TESTING.md).
