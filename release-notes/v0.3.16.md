# Diffusion v0.3.16 — Release Candidate Checklist

> **Release preparation, not proof of a stable release.** Do not publish as a stable GitHub Release until the acceptance evidence below is attached to this specific release commit and its exact Windows installer.

## Product summary

Diffusion is a local-first spatial workspace for exploring ideas before commitment. Write and arrange Thoughts in a Field, scope optional thinking actions, inspect provisional AI Ghosts, explicitly confirm relations, and create Crystals by your own decision.

## What's included

- Current integrated Field management: create, open/switch, duplicate and rename Fields; contextual actions and navigation.
- Human-controlled Thought/Ghost/Crystal interactions, scoped AI/provider options and optional Search & Evidence features.
- English and Simplified Chinese README, new bilingual hands-on user guides, and a reorganized documentation index (PR #69).
- Windows x64 native app built with Tauri and the bundled discovery engine.

These descriptions are not claims that live providers or installed Windows scenarios have passed release acceptance.

## Known limitations / user warnings

- Existing `0.3.16` preview was built from `bd9cc76` and has **not** been qualified as the stable installer; do not relabel or reuse it as the final release binary.
- Local-first does **not** mean cloud synchronization. Export JSON backups and keep original imported file bytes separately; JSON excludes unclaimed Ghosts and originals, and Markdown cannot restore a project.
- Installed Windows, real AI, search quality, older-storage upgrades and extended sessions have separate acceptance gates. CI/E2E alone does not clear them.
- Other OS installers are not announced as official stable artifacts.
