# 自由连线整合试用

本实验根据 A 的反馈接入现有 Field，复用 ProjectController、项目关系存储、保存队列和统一 Undo/Redo。以 #88 的 5e4f979 为代码基线，未接入之后 #91 的语言实验。

浏览器入口追加 `freeLinksTrial=1`；原路径默认不启用。独立 Windows 配置为 `src-tauri/tauri.free-links.conf.json`，应用名称 Diffusion Free Links，标识 app.diffusion.explorer.freelinks。它使用独立项目和凭据空间，不覆盖原 Diffusion 或复制原数据。

## 操作

- 本地阅读尺度中，已保存的卡片两侧显示圆点，拖到另一张已保存卡片创建联系。未 Keep 的建议不能作为端点，不会因连线自动 Keep。
- 支持多个来源；两张卡片只允许保留一个方向，拒绝同向重复及直接反向互连。旧版已存的反向联系不自动删除，管理器可明确选择保留的方向并撤销。手动联系不改写 derivedFrom、organizingParentId、原始来源、正文、层级或卡片位置，不代表事实认证，也不调用模型。
- 右上角“··· → 管理连线”和命令面板共用 manage-links 命令。面板提供新建、换起点、换终点、删除、查看两端及 Undo/Redo；被挡住的线也能从列表操作。
- 改接可以点画布卡片/圆点或在列表中选左右点。每次完成一个 Core 命令；取消保留旧线。保存并恢复实际选择的端点，移动中使用 Field 同一帧的临时几何预览。
- 启用本实验时，移动卡片不会自动执行近距离 AI Probe，仍可通过显式动作邀请 AI。关闭实验保持原行为。
- 语义缩放、折叠和离屏裁剪仍由现有 Field 管理；隐藏端点的线不强行显示，管理面板可定位。

## 可选数据与兼容

沿用 Relation 的 bridge 类型，增加可选 `manual: { aPort: 'left' | 'right', bPort: 'left' | 'right' }`，标识用户手动联系及显示端点。创建/改接使用 user relation.confirm，删除使用 user relation.remove；改接保持 ID 和创建时间。Core 与导入校验拒绝不合法的端点。

这是用户明确要求的试用扩展，不把当前产品规范中的旧版无 Connect Tool 约束解释成默认采用本方案。普通关系、AI 候选及来源箭头保持原语义。没有新表、数据库升级或导出版本变化；旧记录无需补写字段。旧客户端是否保留手动端点未经资格验证，不应将试用项目覆盖回旧版原项目。

独立 HTML 原型导出的 JSON 不等于正式项目格式。本整合版使用 Diffusion 自己的项目导入导出；在原软件导出副本后，可在试用版通过导入恢复为独立项目，旧原件保持不动。

## 验收范围

目标 Core 测试覆盖多来源、循环、来源不变、权限、非法端点、改接/删除 Undo/Redo、Dexie 关闭重开及 JSON 校验。实际挂载浏览器测试覆盖拖连接点、多来源、改接、删除、统一撤销、刷新保存及零模型调用。安装包编译、安装和 WebView 验收需单独记录，不能用浏览器测试代替。

路由仅为可操作原型：复杂拥挤布局下尚未完成全局避障/性能验收。反向端点采用上方绕线，仍可能与第三张卡片交叉；可从管理列表确认与定位。不宣称任意布局下所有线都不遮挡。

连线样式：常态使用细浅线，选中后加深；透明点击范围仍保留 20px，端点按钮仍为 22px。

## 请大家试用后评审：是否加入原软件

这是一份待讨论的自由连线试用方案，请大家先试用，再判断是否采用。没有把它作为原软件的默认功能。

浏览器试用：安装锁定依赖后执行 `pnpm dev`，打开终端给出的本地地址，并在网址后加 `?locale=zh&freeLinksTrial=1`。Windows 构建使用 `pnpm exec tauri build --config src-tauri/tauri.free-links.conf.json --bundles nsis`，需按项目文档准备原生构建环境与搜索组件。

建议用三张测试卡片试这几件事：

1. 从第一张卡片的圆点拖到第二张，看看连线是否自然、是否容易看清两端。
2. 从右上角“··· → 管理连线”换起点、换终点、删除，再用撤销恢复。
3. 试着再连第二张到第一张，确认会阻止反向互连；关闭重开，确认原连线仍在。
4. 移动卡片，确认连线和选中框跟着走。

请直接反馈：哪个动作难操作、哪条线看不清、是否比现有操作省事。对于是否整合进原软件，请说明“建议加入 / 修改后加入 / 暂不加入”及原因；界面入口、线条样式和方向限制都可以提出不同意见。
